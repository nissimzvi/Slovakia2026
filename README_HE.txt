העלאה ל-GitHub Pages
====================
1. חלץ את קובץ ה-ZIP.
2. העלה למאגר Slovakia2026 את הקבצים עצמם:
   index.html, styles.css, app.js, manifest.webmanifest, sw.js
3. ב-GitHub פתח Settings > Pages.
4. תחת Source בחר Deploy from a branch.
5. Branch: main, Folder: /(root), ואז Save.
6. האתר יופיע בכתובת:
   https://nissimzvi.github.io/Slovakia2026/

הערה: המפות מבוססות OpenStreetMap ודורשות אינטרנט.
